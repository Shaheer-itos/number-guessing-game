# Number Guessing Game 🎯

A beginner-friendly Python game. The computer picks a secret number and you try to guess it, with hints after every guess.

## Features
- Three difficulty levels (Easy, Medium, Hard)
- Limited number of guesses
- "Higher" / "Lower" hints
- Handles wrong input (letters or numbers out of range)
- Play again option and a simple score counter

## How to run
1. Install Python 3
2. Download `number_guessing_game.py`
3. Open a terminal in the same folder and run:

```
python number_guessing_game.py
```
